# Recordly Pro (baseline phase)

For now this repository intentionally mirrors the current stable Recordly application.
Premium functionality is deferred until the shared account and subscription architecture is designed and tested.

Important:
- This is a frontend/code baseline, not a database migration.
- Do not run schema.sql against production without first backing up and reviewing it.
- Keep the existing Supabase project URL and anon/publishable key. Never put a service-role key in frontend code.
- GitHub Pages should deploy from the repository root (main / root).
